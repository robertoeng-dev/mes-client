# Scripts legados da v1.0.5

Estes scripts PowerShell sao da **v1.0.5** (station.id, mes_db, mes_user) e **nao servem para o Proteus Client 2.0**.
Ficam aqui so como referencia para estacoes que ainda rodam a v1.0.5.

- Windows 10/11: use `installer\MES_Client_Setup.iss` (gera `Proteus_Client_Setup_v2.0.0.exe`).
- Windows 7 SP1: use a edicao separada em `win7\` (gera `Proteus_Client_Setup_v2.0.0-win7.exe`).
